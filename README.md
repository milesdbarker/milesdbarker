### Hi there 👋

My name is Miles Barker (he/him), and I like solving problems. Let's connect on [LinkedIn](https://www.linkedin.com/in/milesbarker732/)

Recently I have been working on [Doppelt](https://github.com/milesdbarker/doppelt). This is a Reinforcement Learning agent built with pytorch RL and trained on self-play. My goal is to make an agent that is better than me at the game so that I can learn optimal strategies. Currently it has achieved an average of 266.8 score, while my approximate average is 280, so it is very close to better than human play! Hopefully by the time you read this, I have achieved a higher score.

In college I collaborated with my friend [Hayden](https://github.com/Koalacards) on a few fun discord bots:

**Bots:**

[Doxcord](https://github.com/Koalacards/Doxcord) is a fun bot that assigns fake information to users in the server. Current functionality includes fake names, addresses, phone numbers, blood types, and more. Users can always opt out, and we make sure that all information is not real in any way.

[Sus-O-Meter](https://github.com/Koalacards/Sus-O-Meter) is a bot that looks through message history in the server and determines the most 'sus' users. Servers can decide their own word list used, and includes functionality in English and Spanish!
